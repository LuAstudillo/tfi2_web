# Busca Hoteles Ya
## Descripción
 Mi trabajo se trata sobre un sitio de búsqueda de hoteles.
## Nombre completo
 Lourdes Nicole Astudillo Durán.
## Instrucciones de uso
1. Abrí el  link de GitHub Pages, para entrar al sitio.
2. En la página de inicio hay una breve introducción y un carrusel con funcionamiento sencillo con botones "Anterior y Siguiente".
3. Elegí un destino en el sitio, se pueden ver distintas opciones de hoteles.
4. Completa el formulario de contacto si surge alguna duda.
5- El formulario de contacto tiene validaciones y en caso de poner datos inválidos o vacíos, se mostrará un mensaje por pantalla.
